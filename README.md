# Ανεξάρτητος Admin (Android)

Android εφαρμογή διαχείρισης WordPress για το anexartitos.gr.

Η εφαρμογή συνδέεται με WordPress Application Password (όχι με τον κανονικό κωδικό). Το GitHub Actions παράγει δοκιμαστικό APK, χωρίς να αποθηκεύει στοιχεία σύνδεσης.

Ο κώδικας προέρχεται από το αρχικό πακέτο της εφαρμογής και μεταφέρεται στο αποθετήριο για αυτόματη μεταγλώττιση.
